# Portafolio

Mi hoja de vida en formato web, con estilo de videojuego retro (8 bits). Bilingüe español / inglés.

Hecho con HTML, CSS y JavaScript, sin frameworks ni dependencias.

## Estructura

```
index.html       estructura de la página
css/style.css    estilos
js/data.js       contenido (experiencia, skills, proyectos, etc.)
js/sprite.js     avatar pixel
js/main.js       render, idioma y animaciones
docs/cv.pdf      hoja de vida descargable
```

Para actualizar la información solo hay que editar `js/data.js`.

## Correr localmente

Abrir `index.html` en el navegador, o usar Live Server en VS Code.

## Deploy

Publicado con GitHub Pages desde la rama `main`.
